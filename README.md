# Khushie Niteen Mohod - Personal Portfolio

Welcome to the repository for my personal portfolio website! This static site showcases my journey as a Computer Engineering student (Department Rank 2) at PCCOE, my leadership as the Management Head of the ACM Student Chapter, and my passion for building robust, data-driven software solutions.

## Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Contact Form Backend:** Formtorch (Serverless form handling with built-in TorchWarden spam filtering).
* **Hosting & Deployment:** GitHub Pages.

## Design & Color Palette
The website features a custom dark-themed UI designed for maximum contrast and elegance, using the following color palette:
* **Main Background:** `#22223b`
* **Form Card Background:** `#4a4e69`
* **Text & Icons:** `#f2e9e4`
* **Accent & Buttons:** `#c9ada7`
* **Subtle Details & Borders:** `#9a8c98`

## Key Features
* **Project Case Studies:** Detailed breakdowns of my complex projects, including **AtomTrack** (Next.js Enterprise Web App), **TrustWise** (RAG AI Pipeline), and **CivicFix** (Civic Reporting Platform).
* **Verifiable Credentials:** A dedicated Certifications section featuring locally hosted certificates (e.g., Google Cloud Cybersecurity, Udemy DSA) for immediate verification.
* **Functional Contact Form:** A fully functional, static contact form powered by a Formtorch endpoint that securely routes messages directly to my inbox without needing a custom backend server.

## Local Setup
Since this is a static frontend website, no build step or complex installation is required. 
1. Clone the repository: `git clone https://github.com/KhushieMohod/your-repo-name.git`
2. Open the directory and launch `index.html` in any modern web browser. As the standard entry point for the web, the browser will render it immediately.
3. All assets (profile images, certificate PDFs) are stored locally within the `assets/` directory.
